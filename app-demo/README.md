# Music Industry Lap — Interactive Demo

เปิด [index.html](index.html) ในเว็บเบราว์เซอร์เพื่อทดลองต้นแบบแบบ local โดยไม่ต้องติดตั้งแพ็กเกจหรือเชื่อมบริการภายนอก

## เส้นทางที่ทดลองได้

1. **สำรวจ** บทบาทดนตรี 6 สาย ดูงานและทักษะที่เกี่ยวข้อง
2. **ทดลอง** ภารกิจตัดสินใจ 2 ขั้นของนักแสดง/นักร้อง โปรดิวเซอร์ หรือผู้จัดงาน แล้วอ่าน feedback และสะท้อนสิ่งที่สนใจ
3. **คน/ที่เรียน** เลือกสาย รูปแบบเรียน งบเดือนแรก และความต้องการยืมเครื่อง ระบบกรองข้อมูลตัวอย่างและแสดงสูตร `4 × ค่าเรียนต่อครั้ง + ค่าเพิ่ม + 4 × ค่าเดินทางต่อครั้ง`
4. **ทางของฉัน** ทำเครื่องหมายแผน 8 สัปดาห์ และบันทึกโอกาสชุมชนตัวอย่าง
5. **ครูลงงานสอน** เปิด [teacher-studio.html](teacher-studio.html) เพื่อกรอกบริการสอน บันทึกร่าง ดูตัวอย่างรายการและคำนวณค่าเรียน 4 คาบ แล้วกดส่งตรวจในโหมดจำลอง

ข้อมูลที่ทำเสร็จและรายการที่บันทึกเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น ข้อมูลครู ราคา สถานที่ และกิจกรรมทั้งหมดเป็น **ข้อมูลสมมติ** เพื่อทดลองการโต้ตอบ ไม่มีการติดต่อ จอง หรือส่งข้อมูลออก

ข้อมูลที่ครูกรอกในหน้าทดลองไม่ถูกนำไปแสดงให้ผู้เรียน และปุ่ม “ส่งตรวจ” บันทึกสถานะตัวอย่างในเครื่องเท่านั้น ไม่มีทีมตรวจหรือการเผยแพร่จริง

## ขอบเขต

ต้นแบบนี้ทดสอบ UX flow และตรรกะพื้นฐาน ยังไม่มีฐานข้อมูลผู้สอนจริง การยืนยันตัวตน ระบบรับไฟล์เสียง การจับคู่ผู้ใช้จริง หรือผลการทดสอบกับผู้เรียนจริง ภารกิจเป็นสถานการณ์สั้นเพื่อรู้จักบทบาท ไม่ใช่หลักสูตรฝึกเครื่องดนตรีหรือแบบทดสอบความถนัด

อ่าน [ที่มาของหลักการออกแบบ](../docs/5-product/03-design-transfer.md) และ [Use case ตลาดครูและแรงจูงใจ](../docs/4-users/05-teacher-marketplace.md) ก่อนใช้ต้นแบบประกอบการตัดสินใจผลิตภัณฑ์
