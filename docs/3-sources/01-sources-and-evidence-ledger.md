# แหล่งข้อมูลหลักและทะเบียนหลักฐาน

รวม "แหล่งข้อมูลหลัก" (กรอบสากลและสถาบัน) กับ "ทะเบียนหลักฐานและข้อจำกัด" (ตัวเลขไทย ปี ขอบเขต ข้อห้ามตีความ) ไว้ที่เดียว

## ส่วนที่ 1 · แหล่งหลักด้านการศึกษาดนตรี

ตรวจสอบหน้าเว็บ 25 กันยายน 2026 ใช้แหล่งทางการขององค์กรและสถาบันเป็นหลัก

ลิงก์ curriculum และหน้าโปรแกรมเฉพาะแต่ละสาขาอยู่ติดกับข้อเท็จจริงใน [05-detailed-curricula.md](../1-research/04-detailed-curricula.md); บันทึกความต่างของเอกสารอยู่ใน [06-source-comparison.md](../1-research/05-curricula-comparison.md)

### การใช้แหล่งข้อมูล

ให้เปิดหน้าหลักสูตรอีกครั้งก่อนนำชื่อสาขาไปใช้ในเอกสารเผยแพร่หรือสมัครเรียน เพราะรายละเอียดอาจเปลี่ยนตามปีการศึกษา ชื่อกลุ่มสายงานและโจทย์ simulation ในโครงการนี้เป็นการสังเคราะห์ของผู้จัดทำ ไม่ได้อ้างว่าเป็นรายวิชาของสถาบัน

### การเทียบตัวเลขที่ดูขัดกัน

1. [CEA ข่าว Music Exchange 2026](https://www.cea.or.th/th/news-updates/cea-music-exchange-2026) ยกตัวเลข **3,577.6 ล้านบาทสำหรับปี 2024** ส่วน [CEA/IFPI 2026](https://www.cea.or.th/th/single-research/CEAxIFPI-Thailand) แสดง **3,561.56 ล้านบาท** แต่ไม่ระบุปีฐานในข้อความหน้าเว็บ ความต่าง 16.04 ล้านบาทอาจเกิดจากปีฐาน/วิธีคำนวณ/ปรับปรุงข้อมูล; **ยังไม่สรุปแนวโน้มจากการลบสองตัวเลข** จนตรวจตารางต้นฉบับ
2. สถิติ สช. มีโรงเรียนนอกระบบทั้งประเทศ ส่วนรายชื่อคณะมหาวิทยาลัยมาจาก อว. เป็นคนละระดับการศึกษา และนักเรียนอาจซ้ำหลายระบบ
3. ค่าเรียนต่อเดือนของแต่ละโรงเรียนมีความยาวคาบ รูปแบบกลุ่ม และค่าธรรมเนียมต่างกัน จึงเทียบเป็นราคา 4×60 นาที และแยกค่าแรกเข้า/หนังสือ
4. “รายได้ศิลปิน” เป็นเงินฝั่งผู้รับของธุรกรรมเรียน/แสดง/บันทึกเสียงบางรายการ การรวมกับยอดขายเดิมทำให้ตลาดโตเทียม

### คำถามที่ยังไม่มีคำตอบเชิงปริมาณ

- โรงเรียนดนตรี สาขา และครูอิสระที่เปิดจริง แยกจังหวัดและวิชา
- นักเรียนดนตรีไม่ซ้ำบุคคล แยกวัย เครื่องดนตรี รูปแบบ และจำนวนเดือนที่จ่ายจริง
- โรงเรียนปกติที่มีวงแต่ละชนิดและจำนวนสมาชิก
- หลักสูตร/นักศึกษาดนตรีระดับอุดมศึกษาและผู้สำเร็จการศึกษา หลังกรองข้อมูล อว.
- ร้านเครื่องดนตรีและยอดขาย/เช่า/ซ่อม แยกช่องทาง
- จำนวนการแข่งขันและผู้สมัครโดยปี
- การจ้างงาน รายได้มัธยฐาน และชั่วโมงทำงานตามสายอาชีพ
