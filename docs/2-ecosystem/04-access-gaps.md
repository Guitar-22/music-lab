# รอยรั่วการเข้าถึงการศึกษาดนตรี: ตัวแปรและวิธีวัด

ปรับปรุง 25 กันยายน 2026 | ใช้กับผู้เรียนทั่วไปหลายระดับ | **กรอบออกแบบของโครงการ ไม่ใช่ผลสำรวจช่องว่างของไทย**

## หลักฐานที่ใช้กำหนดกรอบ

[UNESCO Framework for Culture and Arts Education 2024](https://www.unesco.org/sites/default/files/medias/fichiers/2024/04/WCCAE_UNESCO%20Framework_EN_CLT-EDWCCAE20241.pdf) วางเรื่องการเข้าถึง ความเสมอภาค การมีส่วนร่วม วัฒนธรรมท้องถิ่น และการทำงานของหลายภาคส่วนในระบบนิเวศศิลปศึกษา; [UNESCO GEM 2023](https://gem-report-2023.unesco.org/recommendations/) เตือนว่าดิจิทัลช่วยบางกลุ่มได้ แต่ถ้าอุปกรณ์ อินเทอร์เน็ต และการเตรียมครูไม่พร้อม อาจเพิ่มความเหลื่อมล้ำ; [CAST UDL 3.0](https://www.cast.org/what-we-do/universal-design-for-learning/) เสนอหลายวิธีในการมีส่วนร่วม รับข้อมูล และแสดงความรู้; [W3C WCAG 2.2](https://www.w3.org/TR/wcag/) ใช้ตรวจการเข้าถึงเว็บ เช่น คำบรรยาย ทางเลือกข้อความ และคีย์บอร์ด. งานวิจัยกรณีศึกษาดนตรีที่ [UCL](https://discovery.ucl.ac.uk/id/eprint/10053718/) พบอุปสรรคที่มองไม่เห็น เช่น ระยะทาง ขนาด/น้ำหนักเครื่องดนตรี รถของครอบครัว และวัฒนธรรมโรงเรียน; **ไม่ใช้ผลกรณีอังกฤษแทนความชุกในไทย**

## เส้นทางผู้เรียนและจุดหลุด

`รู้ว่ามีทางเลือก → ทดลองครั้งแรก → เข้าถึงเครื่องมือ/ครู → ฝึกต่อเนื่อง → ได้ feedback → เล่น/สร้างร่วมกับคนอื่น → เห็นเส้นทางเรียน/งาน → ได้โอกาสจริง`

ในแต่ละช่วงต้องนับทั้ง **คนที่เข้ามา** และ **คนที่ไปต่อ** พร้อมสาเหตุที่ผู้เรียนสมัครใจบอก; จำนวนคนสมัครหรือดูวิดีโออย่างเดียวไม่เท่ากับการเข้าถึงการเรียนรู้

| รอยรั่ว | ตัวแปรที่ต้องเก็บ (หน่วย/วิธี) | กลไกที่ simulation/ชุมชนช่วยได้ | สัญญาณว่าดีขึ้น | สิ่งที่แพลตฟอร์มแก้ลำพังไม่ได้ |
|---|---|---|---|---|
| ไม่รู้จักบทบาท/ทางเข้า | รู้จักกี่สายงาน, ช่องทางค้นพบ, ภาษาที่เข้าใจ, จังหวัด | ทดลองบทบาทสั้น ๆ และแผนที่ครู/วง/ร้าน/โอกาส | ผู้เริ่มต้นเลือกทางถัดไปได้และอธิบายเหตุผล | การประชาสัมพันธ์ที่เข้าถึงทุกพื้นที่ |
| ค่าเรียนและค่าแฝง | ค่าเรียนจริง/เดือน, หนังสือ, สอบ, เดินทาง, ค่าเครื่องดนตรี, รายได้ครัวเรือนเป็นช่วงโดยสมัครใจ | โจทย์จัดงบ, แสดงต้นทุนรวม, ทางเลือกใช้ฟรี/ยืม/กลุ่ม | สัดส่วนผู้เรียนที่ทำภารกิจจบในงบที่มี; คนกลับมาเรียน | เงินทุน/ทุนการศึกษาและราคาของจริง |
| ไม่มีเครื่องดนตรี/ที่ซ้อม | ชนิดเครื่อง, การเป็นเจ้าของ/ยืม, ชั่วโมงเข้าถึง/สัปดาห์, เสียงรบกวน | งานทางเลือกใช้เสียงร้อง body percussion โทรศัพท์ หรือเครื่องยืม; ตารางห้องซ้อม | งานสำเร็จโดยไม่ต้องซื้ออุปกรณ์; ชั่วโมงซ้อมจริง | ต้องมีเครื่อง/พื้นที่ยืมที่ปลอดภัยและดูแลได้ |
| ระยะทาง/เวลา | นาทีเดินทางเที่ยวเดียว, ค่าเดินทาง, เวลาว่าง, ภาระดูแลครอบครัว | micro-session 15–20 นาที, โหมดทำต่างเวลา, จุดชุมชนใกล้บ้าน | การเรียนต่อเนื่องของคนเดินทางไกล/เวลาจำกัด | ระบบขนส่งและพื้นที่จริง |
| อุปกรณ์/อินเทอร์เน็ต | ประเภทมือถือ, ความเร็ว/เสถียร, ดาต้าที่ใช้, ดาวน์โหลดได้หรือไม่ | ไฟล์เล็ก, เอกสารพิมพ์ได้, บันทึกเสียงออฟไลน์และอัปโหลดภายหลัง | อัตราจบภารกิจในกลุ่มอินเทอร์เน็ตจำกัด | ค่าเครือข่ายและอุปกรณ์ |
| พื้นฐานต่างกัน | ความสามารถก่อนเรียน, การอ่านโน้ต, ประสบการณ์วง, ความมั่นใจ | ภารกิจ 3 ระดับและหลายทางส่งผลงาน; rubric เน้นความก้าวหน้า | ส่วนต่างอัตราจบ/การพัฒนาของมือใหม่กับคนมีพื้นฐานแคบลง | เวลาครูในการโค้ชรายคน |
| ภาษา/วัฒนธรรมไม่ตรง | ภาษาที่ถนัด, แนวเพลง/วัฒนธรรมที่สนใจ, การรู้สึกเป็นส่วนหนึ่ง (สมัครใจ) | ดนตรีไทย/ท้องถิ่น/สากลพร้อมที่มา; เลือกโจทย์และตัวอย่างได้ | ความรู้สึกเป็นส่วนหนึ่งและการกลับมาเรียน | การยอมรับทางสังคมและอคติของผู้ใหญ่/องค์กร |
| ความต้องการเข้าถึงเฉพาะบุคคล | วิธีรับข้อมูล/ลงมือที่ต้องการโดยไม่บังคับเปิดเผยการวินิจฉัย | คำบรรยาย/ถอดเสียง, ภาพจังหวะ, คีย์บอร์ด, ความเร็วปรับได้, ทางส่งงานหลายรูปแบบ | งานจบและคุณภาพการเรียนของผู้ใช้ทางเลือก; ปัญหาการเข้าถึงลดลง | บางรายต้องการอุปกรณ์/ผู้เชี่ยวชาญเฉพาะ |
| ขาดครู/feedback | เวลารอ feedback, จำนวนรอบแก้, อัตราครูต่อผู้เรียน, คุณภาพ feedback | peer review มีเกณฑ์, นัดครู/พี่เลี้ยง, ตัวอย่างงานระดับต่าง ๆ | ได้ feedback ภายในเวลาที่กำหนดและแก้งานได้จริง | จำนวนครูที่มีคุณภาพและค่าตอบแทน |
| ไม่มีเครือข่าย/โอกาส | จำนวนวง/ครู/กิจกรรมใกล้บ้าน, ใครได้รับเชิญ, ประวัติการสมัคร | โปรไฟล์ผลงาน, จับคู่วง/ออดิชัน/ทุน/เวที, โอกาสที่ยืนยันแหล่ง | ผู้เริ่มต้นและต่างจังหวัดได้โอกาสมากขึ้น | จำนวนงานและการคัดเลือกของผู้จัด |
| ความปลอดภัย/สิทธิ | อายุ, การยินยอมผู้ปกครอง, การเปิดเผยตำแหน่ง, สิทธิของเสียง/ภาพ | สถานการณ์ตัดสินใจเรื่องอนุญาต, โหมดโปรไฟล์เยาวชน, รายงานปัญหา | ไม่มีการเผยแพร่ผลงาน/ข้อมูลโดยไร้สิทธิ; การรายงานได้รับการจัดการ | การกำกับดูแลและผู้รับผิดชอบจริง |
| ไม่เห็นเส้นทางอาชีพ | รู้จักบทบาท, ทักษะจำเป็น, portfolio, ผลงาน/งานจ้างจริง | หมุนเวียนงานหลังเวที/ธุรกิจ/เทคนิค ไม่ยึดแต่ศิลปินหน้าเวที | ผู้เรียนบอกขั้นต่อไปได้และมีชิ้นงานใช้สมัคร | ตลาดงานจริงและการฝึกงาน |

**ตัวแปรกำกับ** ที่ควรดูประกอบ: อายุ/ระดับเรียน จังหวัด เมือง–ชนบท ประเภทโรงเรียน/ไม่มีสังกัด ประเภทเครื่องดนตรี ระดับเริ่มต้น เพศ/ความพิการ/รายได้เฉพาะเมื่อสมัครใจและมีเหตุผลจำเป็น รวมถึงชนิดอุปกรณ์ เวลา และรูปแบบเรียน. เก็บเท่าที่จำเป็น ใช้ผลแบบกลุ่ม และไม่แสดงข้อมูลเด็กเป็นสาธารณะ

## วิธีวัดโดยไม่หลงกับจำนวนสมัคร

1. **Reach** = คนเป้าหมายที่เริ่มภารกิจ / คนเป้าหมายที่ได้รับเชิญ (ต้องระบุฐานและจังหวัด)
2. **Activation** = คนที่ส่งงานชิ้นแรก / คนที่เริ่มภารกิจ
3. **Learning** = คะแนน rubric หลัง – ก่อน หรือร้อยละที่ทำทักษะเป้าหมายได้; ให้ประเมินด้วยชิ้นงานจริง
4. **Continuation** = คนที่กลับมาทำภารกิจถัดไปใน 30 วัน / คนที่จบภารกิจแรก
5. **Opportunity** = การจับคู่ที่ผู้เรียนและองค์กรยืนยันผล / คนที่ขอโอกาส
6. **Equity gap** = ความต่างของอัตรา Activation/Learning/Continuation ระหว่างกลุ่มที่มีอุปสรรคกับกลุ่มอื่น โดยรายงานขนาดตัวอย่างและไม่ตีความเชิงเหตุผลหากไม่ได้ออกแบบศึกษา
7. **Cost to participate** = เงินสด + เวลาเดินทาง + ชั่วโมงที่ต้องใช้อุปกรณ์ของผู้เรียนต่อภารกิจ; แสดงค่ามัธยฐานและช่วง ไม่ใช้ค่าเรียนอย่างเดียว

**ข้อควรระวัง**: คะแนนดนตรีที่ดีขึ้นใน simulation ยังไม่พิสูจน์ว่าช่องว่างการศึกษาทั้งประเทศลดลง ให้เปรียบเทียบกับก่อนใช้/กลุ่มที่มีเงื่อนไขใกล้เคียง และสัมภาษณ์คนที่ออกกลางทางเพื่อหาสาเหตุ

## คันโยกที่ควรเริ่มก่อน

สำหรับรุ่นนำร่อง ให้ใช้ทางเข้า **ฟรี + ไม่ต้องมีเครื่องดนตรี + มือถือเครื่องเดียวหรือกระดาษ + ทำต่างเวลาได้ + มี feedback คนจริงอย่างน้อยหนึ่งรอบ** แล้วค่อยเชื่อมครู วง ร้าน และพื้นที่ซ้อมในจังหวัดนำร่อง การออกแบบนี้เป็นข้อเสนอที่ควรทดลอง ไม่ใช่ข้อพิสูจน์ว่าทุกชุมชนต้องการเหมือนกัน
