# ตารางตรวจข้อมูล

รัน `node build-audits.cjs` ในโฟลเดอร์นี้เพื่อสร้าง CSV ตั้งต้นจากข้อมูลใน Portal. ไฟล์เหล่านี้เป็น **snapshot** ที่สร้างใหม่ทุกครั้ง; ถ้าจะบันทึกผลตรวจด้วยมือ ให้คัดลอกเป็นไฟล์ทำงานแยกก่อนรันซ้ำ

- `resource-audit.csv`: 35 แอป/เว็บ พร้อมแหล่งต้นทาง ภาพ candidate และสถานะตรวจไอคอน/เปิดจริง
- `university-audit.csv`: 25 สถาบันอุดมศึกษา พร้อมสาขาและแหล่งหลักสูตร
- `school-group-audit.csv`: 11 กลุ่มโรงเรียนหรือคอร์ส พร้อมจำนวนจุดเรียนที่ระบุชื่อ
- `bangkok-district-audit.csv`: 50 เขต, 6 ประเภทคำค้นต่อเขต, รวม 300 ลิงก์ Maps สำหรับการตรวจทีละโซน

ค่า `not_scanned`, `not_checked`, `needs_...` คือค้างงานจริง ไม่ใช่ผ่านแล้ว; การพบหน้าเจ้าของข้อมูลยังไม่ยืนยันว่าจุดบน Maps ยังเปิดดำเนินการอยู่
